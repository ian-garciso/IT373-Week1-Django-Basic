# Reflection

Setting up the Django environment was both rewarding and challenging. The first obstacle was ensuring the correct Python version and activating the virtual environment (.venv). I initially ran commands outside the venv and fixed this by reactivating the environment before running pip or manage.py. Next, template configuration caused a TemplateDoesNotExist error because I placed base.html in the wrong location and used an incorrect extends path ({% extends "pages/base.html" %} vs {% extends "base.html" %}). I resolved this by moving base.html into templates/pages/ and updating the extends reference, then confirming TEMPLATES['DIRS'] included BASE_DIR / 'templates'. I also encountered "remote origin already exists" when pushing to GitHub; I checked remotes with git remote -v and either removed the incorrect origin or simply pushed to the existing remote. Finally, a 500 error revealed the template issue which I fixed and verified by running python manage.py runserver and loading / and /about/. These debugging steps improved my understanding of Django templates, project structure, and Git workflow.
